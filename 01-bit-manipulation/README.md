# Bit Manipulation

Practice with bitwise operations on fixed-width integers, the kind of code
you write daily when configuring hardware registers.

## Files

- `set_clear_toggle.c` — set, clear, toggle, and check individual bits
- `bitfield_extract.c` — extract and insert bit fields within a register
- `trailing_zeros.c` — count leading and trailing zero bits
- `endian_swap.c` — swap byte order for 16-bit and 32-bit values
